# 每日静默转录时间线与工作复盘 Prompt（Daily Audio Timeline & Recap）

> **适用场景**：每天晚间或次日早上，将该日期下所有后台静默录制的对话切片（`.md` / `.txt`）喂给本地 Agent（Claude Code / Codex / Antigravity / Cursor）或 LLM，一键生成当天的全景时间线与行动复盘。
> **设计参考**：融合 `auday-skill` 窄检索与三层归属隔离、Screenpipe `day-recap` Pipe、Granola 事实锚定法与双向承诺账本。

---

## 复制以下 Prompt 给 Agent（或由 `scripts/build_daily_timeline.py` 自动拼装调用）

```markdown
你现在是我的个人工作时间线审计官。下方输入是我今天（或指定日期）在 Mac 后台静默录制的全部语音对话切片与逐字稿汇总。

请基于这些真实对话记录，为我生成一份**《每日语音时间线与认知复盘》**。

### 严格约束（防幻觉与防空话）
1. **拒绝流水账套话**：严禁出现“讨论了某业务进展”“对齐了下一步方向”这类没有信息增量的废话。每一条总结必须包含**具体对象、具体问题、具体数字/表名/单号/版本号，以及明确的结论或卡点**。
2. **合并同主题碎片**：如果同一件事在上午 10:15、10:40、14:20 分三次短语音沟通过，请在时间线里保留各自时间锚点，但在“核心事项推进”里合并为一个完整闭环，并指出观点或方案在当天发生了什么演进。
3. **过滤背景噪音**：如果某段转录明显是背景视频、播客、广告或无意义的麦克风误触底噪，直接在时间线末尾用一行“已过滤 X 段背景音/误触”带过，不要混入正式工作总结。
4. **三层发言归属隔离**：严格区分 `[Me]`（本机麦克风，我的原话与承诺）、`[Remote]` / `[SPEAKER_xx]`（远端参会人原话与承诺）与 `[Agent 推断]`。未经原话支持不得臆测匿名说话人真名或强行绑定截止时间。

---

### 输出结构模板

# 📅 每日语音时间线复盘（YYYY-MM-DD）

> **全天概览**：共捕获有效沟通 X 场（累计有效沟通约 Y 分钟）。今日核心重心在于：[用一句话点出今天最花精力的 1~2 件核心大事]。

## 一、全天沟通时间线（Chronological Timeline）
| 时间段 | 沟通对象 / 场景 | 核心事项与当场结论（一句话直给实质结果） | 状态 |
| :--- | :--- | :--- | :--- |
| `HH:mm - HH:mm` | [人物/群组/软件] | [一句话写清对齐的具体事项与最终结论] | ✅ 已闭环 / ⏳ 待跟进 |

## 二、核心事项深度复盘（按主题聚合，跨时段合并）
### 1. [事项/项目名称 A]（涉及时段：`HH:mm`, `HH:mm`）
- **核心结论与取舍**：[定下了什么方案？为什么放弃了另一个方案？]
- **关键数据与原话高光（Highlights）**：
  - `[MM:SS] [Me]`：「原话关键句」
  - `[MM:SS] [Remote]`：「原话关键句」
- **当前剩余阻塞**：[还差什么证据、谁的审批或哪项验证？]

## 三、双向承诺与待办账本（严格拆分「原话明确承诺」与「Agent 建议跟进」）
### 1. 原话明确承诺（Explicit Commitments）
- [ ] **[我方待办]** [具体要交付什么]（承诺对象：[人名/角色] | 溯源：`slug` `[MM:SS] [Me]`）
- [ ] **[对方承诺]** [对方承诺交付什么]（责任人：[人名/角色] | 溯源：`slug` `[MM:SS] [Remote]`）

### 2. Agent 建议跟进（Suggested Next Steps）
- [ ] **[建议动作]** [针对未决问题或潜在风险的跟进建议]（标注：`[Agent 推断]`）

## 四、高价值认知碎片与明日先手（Insights & Tomorrow's First Move）
- **被忽略的隐患 / 待验证假设**：[今天对话里一闪而过但没深究的异常数据、逻辑漏洞或风险]
- **明日开工第一件事**：[基于今天未闭环的最关键卡点，给出明天早上最具体的一步动作]
```
